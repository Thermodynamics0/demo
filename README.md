# quick-timestamp-id-demo

A hands-on demonstration showing how to use `quick-timestamp-id` in Node.js applications.

## Features Demonstrated

- Entity-prefixed ID generation (`usr_...`, `ord_...`, `txn-...`)
- Parsing IDs back into their original UTC timestamp and random tokens
- Performance benchmark and collision uniqueness testing

## Running the Demo

```bash
# Install dependencies
npm install

# Run the demo
npm start
```
