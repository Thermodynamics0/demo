quick-timestamp-id

View on npm ↗

Lightweight timestamp-prefixed
unique ID generator

Zero dependencies. Cryptographically random. Sortable by creation time. Human-readable prefix support.

$ npm install quick-timestamp-id

Generate IDs

const { generateId } = require('quick-timestamp-id');

// Default
generateId();
// → id_mws5yyoe_yyj3iDg1

// With prefix
generateId({ prefix: 'usr' });
// → usr_mws5yyof_3okBi8Q8

// Custom delimiter & length
generateId({
  prefix: 'txn',
  delimiter: '-',
  randomLength: 10
});
// → txn-mws5yyof-VstdcRF0ab

Parse IDs

const { parseId } = require('quick-timestamp-id');

const result = parseId('ord_mws5yyof_Xqn2sT');

console.log(result);
// {
//   prefix:      'ord',
//   timestamp:   Date (UTC),
//   timeToken:   'mws5yyof',
//   randomToken: 'Xqn2sT'
// }

// Recover exact creation time
result.timestamp.toISOString();
// → "2026-11-22T18:22:07.119Z"
